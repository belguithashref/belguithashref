### 🔀 Orchevia — Agentic AI Workflow Engine
[![Orchevia demo](https://img.youtube.com/vi/E2Wlp5tRKcY/hqdefault.jpg)](https://youtu.be/E2Wlp5tRKcY)

A workflow engine where AI can reason, make decisions, use tools and run multi-step automations.

- Custom engine: DAG execution, conditional branches, tool calling, execution history
- Reliability: retry classification, exponential backoff with jitter, timeouts, deadlines, Pydantic validation
- Multi-provider LLM layer: **Groq, Gemini, OpenRouter** and local models with **Ollama**, chosen per step
- Workflows generated from a plain-English description
- Live run tracking with Server-Sent Events
- Integrations: Facebook Messenger, Slack, Google Sheets
- Containerized with Docker Compose, deployed on Oracle Cloud

`Python` `FastAPI` `Pydantic` `PostgreSQL` `SSE` `Docker`

### 🏛️ Safar 360 — AI Historical-Character Chatbot · *Freelance client project*
[![Safar 360 demo](https://img.youtube.com/vi/WZNFXA39X3w/hqdefault.jpg)](https://youtu.be/WZNFXA39X3w)

Users chat with historical figures (Hannibal, Nikola Tesla…), each answering in their own style.

- FastAPI backend, React chat interface, PostgreSQL
- Gemini / Vertex AI for the character conversations
- Voice input with speech-to-text
- Credits system with Paddle payments (credit used only on a successful AI answer)
- Deployed to production on AWS

`FastAPI` `React` `PostgreSQL` `Gemini` `AWS` `Paddle`

### 📄 DocuChat — Chat with your Documents (RAG)
